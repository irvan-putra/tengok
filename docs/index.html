What tengok opens today
  • MIDI (.mid, .midi, .rmi): format, tracks and instruments, a piano roll, playback, and a play-along game with a live rank.
  • Images: zoomable viewer, using this browser's decoders.
  • Audio: a simple player, using this browser's decoders.
  • Text: monospace reading view, UTF-8 with a Latin-1 fallback.
  • Everything else: a paged hex view plus the file's facts (declared type, detected type, size, SHA-256).
Honest limits of the web version
  • PDF, video, SVG, office documents and archives open in the hex/details view for now, exactly like Android tengok 0.3.2. Rich viewers for them are on the roadmap.
  • MIDI plays through a simple built-in synth: browsers ship no General MIDI sounds, so instruments are approximate and pitch bends are not rendered.
  • A real MIDI keyboard needs Web MIDI (Chrome and Edge have it; Firefox and Safari do not). The on-screen and letter keys work everywhere.
  • HEIC and AVIF photos only display in browsers that ship those decoders.
  • No folder browsing or recent-files list yet: this build starts each visit fresh. Some browsers can re-grant folder access with the File System Access API, so this may come later.
  • The Android app remains the full tengok: it opens files from any app, remembers folders, and uses the phone's own MIDI synth.
Converting files

tengok also converts between formats, always offline: the original file stays untouched and the result downloads as a new file. Open a file and look for the Convert card. Supported pairs are listed there honestly, including what quality loss each target means. MIDI to audio (rendered with the built-in synth) is planned, and wider engines for video and documents are being assessed.

Conversion ideas to revisit

Ideas from the project's owner, recorded here so they are not lost. These are not working features yet:

  • Text to image: render writing as a picture.
  • Image to text: OCR, reading the words out of a photo.
  • Music to PDF: sheet notes. Two different ideas hide here: printing notation from a format that already has notes (like MIDI), and transcribing raw audio into notes, which is much harder.
  • Voice to PDF: transcribe speech into a document.
